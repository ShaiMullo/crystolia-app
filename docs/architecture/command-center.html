✓ Invoice PDF Generation — Resolved (2026-03-17)
POST /api/invoices/:id/issue calls Green Invoice API (sandbox by default) → stores pdfUrl + greenInvoiceDocId on Invoice, sets status=issued. Admin "Issue & PDF" button in invoices tab opens PDF in new tab. To activate: fill GREEN_INVOICE_API_ID / GREEN_INVOICE_SECRET in Helm secrets and set GREEN_INVOICE_SANDBOX=false for live invoices.
⚠️ Caveats (verification pass 2026-03-17): All API field names, endpoint paths, and response shapes are assumptions — must be confirmed in sandbox before live use. income[0].price = totalAmount assumes pre-VAT amount; if stored amount is VAT-inclusive, PDF totals will be wrong. Bug fixed: issuedAt date now captured before service call so PDF date and DB record share the same timestamp.
✓ Auto Invoice from Order — Resolved (2026-03-17)
PATCH /api/orders/:id now auto-creates a draft Invoice when status=approved. Idempotent: Invoice.findOne({order}) check prevents duplicates. Invoice number: INV-{YYYY}-{6-digit-timestamp}. Failure is isolated and never breaks the order update response.
